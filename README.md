----- Preguntas Hanzu Vives Respuesta ----------

### 1. ¿Cuál es la diferencia entre `git add` y `git commit`?

**Respuesta:** `git add` prepara cambios; `git commit` los guarda en el historial.

### 2. ¿Cuál es la diferencia entre `git push` y `git pull`?

**Respuesta:** `git push` sube cambios; `git pull` descarga cambios.

### 3. ¿Cuál es la diferencia entre un repositorio local y uno remoto?

**Respuesta:** El local está en tu computadora; el remoto está en un servidor.

### 4. ¿Qué problema resuelve una rama?

**Respuesta:** Permite trabajar en cambios separados sin afectar `main`.

### 5. ¿Qué diferencia existe entre `git merge` y `git rebase`?

**Respuesta:** `merge` une ramas; `rebase` reorganiza los commits sobre otra rama.

### 6. ¿Por qué ocurre un conflicto?

**Respuesta:** Cuando Git no puede combinar automáticamente cambios incompatibles.

### 7. ¿Quién debe decidir cómo resolver un conflicto?

**Respuesta:** El desarrollador que conoce el propósito de los cambios.

### 8. ¿Qué problema resuelve un Pull Request?

**Respuesta:** Permite revisar y proponer cambios antes de integrarlos.

### 9. ¿Por qué es recomendable revisar un Pull Request antes de integrarlo?

**Respuesta:** Para detectar errores y asegurar la calidad del código.

### 10. ¿Qué ventaja tiene trabajar en una rama en lugar de modificar directamente `main`?

**Respuesta:** Permite desarrollar y probar cambios sin afectar la versión principal.
